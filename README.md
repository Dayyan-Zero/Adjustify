# Adjustify

![adjustify banner](https://raw.githubusercontent.com/Dayyan-Zero/Adjustify/external/adj_banner.png)

## About

**Adjustify** is my personal vision for what Minecraft could be. The aim is to get the game feeling like a well woven tapestry, polished and pleasing to the eye. It's meant to build off of Vanilla and make improvements where needed. 

Features include things like: improved models (better doors, Re-Creatures are included), longer grass blocks, better slabs, alternate plants and blocks, better Glazed Terracotta, unified workbenches, GUI tweaks, more "human-ish" Villagers and Illagers.

### Supported Version

Adjustify only supports Minecraft 1.20.1 at this time. The rapid update cadence and multi-layered levels of technical change brought every several months makes updating extremely time-consuming. Therefore, I've chosen to focus on the version I play the most, which is also the most modern community supported version (for modding and the like). Things may change in the future, but for now, this is the current direction.

## Contributing

If you'd like to contribute to the development of Adjustify, here are some guidelines:

1. If you are familiar with GitHub, create a new issue, add your suggested additions, changes, improvements, and/or updates, and submit. 
2. If you are unfamiliar with GitHub, you can upload your suggested contribution on the discord server and it'll be uploaded as an issue on your behalf.

I'll then review and filter suggestions, and if they match with the vision of the project, they'll be added into development.

> [!NOTE]
> For those who know what they're doing, please make pull requests to the `dev` branch.
> 
> This would be a great help, especially when it comes to updates and bug fixes!
